# Zyner Frontpage

## Development

### Flake

It is recommended to use the Nix flake devshell for development, it can be
activated by running `nix develop` in the project root or using a tool such as
[direnv](https://direnv.net/).

### Commands

| Command           | Description                                |
| ----------------- | ------------------------------------------ |
| `npm run dev`     | Starts the development server              |
| `npm run build`   | Builds the application for production      |
| `npm run preview` | Previews the production build              |
| `story:dev`       | Starts the histoire development server     |
| `story:build`     | Builds the histoire stories for production |
| `story:preview`   | Previews the histoire production build     |
